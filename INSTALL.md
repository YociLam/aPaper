# Installation / 安装

## Requirements

Apple silicon Mac running macOS 14.6 or later.

## Install

When an installer is available in [Releases](https://github.com/YociLam/aPaper/releases):

1. Download **aPaper.dmg**. GitHub's Source code archives are repository snapshots, not the App.
2. Open the disk image and drag aPaper to Applications.
3. Eject the disk image and open aPaper from Applications.

To verify a download, run `shasum -a 256 aPaper.dmg` and compare the result with the checksum for that release. Signing and Apple notarization status are stated in the release notes.

If macOS blocks an explicitly unnotarized release, verify the download and use the per-app **Open Anyway** option in System Settings → Privacy & Security if offered. For a malware or damaged-app warning, contact [support](mailto:contact@apaper.ai).

For manual updates, save your work and quit aPaper before replacing it. Keep backups of important research data.

## 中文说明

系统要求：**Apple silicon Mac，macOS 14.6 或更高版本**。

[Releases](https://github.com/YociLam/aPaper/releases) 提供安装包后，下载 **aPaper.dmg**，打开磁盘映像，将 aPaper 拖到 Applications，推出映像，再启动应用。GitHub 的 Source code 压缩包是仓库快照，不是安装包。

如需校验文件，运行 `shasum -a 256 aPaper.dmg`，与对应版本的校验值比较。签名与 Apple 公证状态见该版本说明。

对于明确标注为未公证的版本，如 macOS 阻止打开，核对下载后可使用系统设置 → 隐私与安全性中针对单个应用的“仍要打开”。如提示恶意软件或应用损坏，请联系[支持](mailto:contact@apaper.ai)。

手动更新前，请保存工作并退出应用。重要研究资料请保留备份。
