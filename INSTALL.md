# Installation / 安装

## Availability

aPaper 0.1.0 is in preparation. No installer is currently available. Requirements: **macOS 14.6 or later on Apple silicon (arm64)**.

## When the installer is published

1. Open this repository's [Releases](https://github.com/YociLam/aPaper/releases) and select the versioned **aPaper.dmg** asset. GitHub's automatic Source code archives are documentation snapshots.
2. Compare the file's size and SHA-256 with the release record. On macOS, run `shasum -a 256 aPaper.dmg`.
3. Open the DMG, drag aPaper to Applications, eject the disk image, and launch the installed copy.

The actual release will state its signing and Apple notarization status. If macOS blocks an explicitly unnotarized package, verify its source and checksum, then use the per-app **Open Anyway** option in System Settings → Privacy & Security if offered. Do not bypass a malware or damaged-app warning; contact [support](mailto:contact@apaper.ai).

## Updates

Follow the update instructions for your installed release. For manual replacement, save your work and quit aPaper first. Keep backups of important research data. Replacing an application does not roll back its data or account state.
