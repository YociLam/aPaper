# Release notes / 版本记录

## 0.1.0 — In preparation / 准备中

The first public aPaper release is being prepared for Apple silicon Macs running macOS 14.6 or later. There is no public installer or announced release date yet.

aPaper 首个公开版本正在准备中，面向 macOS 14.6 或以上的 Apple silicon Mac。目前尚无公开安装包，也未公布发布日期。

The published release will include the final feature notes, version and build, `aPaper.dmg`, exact size, SHA-256, signing and notarization status, and supported update behavior. Checksums will be published with the actual assets.

正式发布时将提供功能说明、版本与构建号、`aPaper.dmg`、文件大小、SHA-256、签名与公证状态，以及实际支持的更新方式。校验值会与安装包一同公布。
