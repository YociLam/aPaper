# aPaper 0.1.2

[English](en.md) · [简体中文](zh-Hans.md) · [繁體中文](zh-Hant.md) · [日本語](ja.md) · [한국어](ko.md)

## 새 기능

- macOS 메뉴 막대에서 빠른 연구를 열고 단축키를 설정하거나 지울 수 있습니다.
- Paper Mentor가 첨부한 PDF를 인용하고 앱 내 미리보기에서 인용 구절을 강조합니다.

## 개선

- 작업공간을 벗어나지 않고 첨부파일을 미리 볼 수 있습니다. 인용 후속 질문은 기본 답변과 동시에 진행되며 대기 중에도 첨부파일을 유지합니다.
- 새 설치에서는 모델이 선택되어 있지 않습니다. 업데이트 시 기존 제공업체와 모델 선택은 유지하고, 지원되지 않는 추론 강도만 자동으로 되돌립니다.

## 수정

- 모든 대상 언어에서 병렬 번역 버튼을 표시합니다. PDF 원문이 대상 언어와 같으면 버튼을 빨간색으로 바꾸지 않고 안내합니다. 주석 삭제 전에 확인합니다.
- 시작 시 캐시된 Ergouzi 모델을 복원하고 연결 해제 시 해당 제공업체를 제거합니다. 인증 코드 발송 성공 후 30초 재발송 대기 시간을 표시하고, 계정 화면을 바꾸면 비밀번호를 다시 숨깁니다.
- 사용자 지정 제공업체의 최초 설정, 첨부파일 제거, Research Assistant 재시도를 수정했습니다.

## 다운로드 및 설치

macOS 14.6 이상이 설치된 Apple silicon Mac에서 [DMG를 다운로드](https://github.com/YociLam/aPaper/releases/download/v0.1.2-b1008/aPaper.dmg)하고, 열어서 aPaper를 응용 프로그램 폴더로 드래그하세요. 수동 업데이트 시에는 aPaper를 종료한 다음 기존 앱을 교체하세요. 자세한 내용은 [설치 가이드](../../INSTALL.md)를 참고하세요.
